# 第二十一章 布局与滑块

第十四章把移动送到了控件手上（拖拽的地基），第二十章末尾留的话是：布局系统可以进场了。本批三件：`set_bounds` 提公开（B10 留给布局故事的位置兑现），`HBox`/`VBox` 排子（排列即控件），`Slider`（第一个吃拖拽地基的控件）。布局的「flex」那一族（比例分配、伸展权重）不在本批，等真有界面要它再议——固定尺寸排开是第一刀。

## set_bounds 提公开：当年留给布局的位置

B10 把 `set_bounds` 设成 protected 时写的理由是「几何是布局故事的决定（Label 重测自己是第一个用户），不是公开旋钮」。布局故事现在到了：盒子排子要挪子控件，跟 Label 重测自己是同一种正当性。提公开，注释改写，欠画申报照旧——换框的人自己不用申报，`set_bounds` 替他报新旧两框，任何重排都不会无声。Widget 同时长出 `child(index)` 取用口：布局的走子需要一扇门，子的归属与次序仍归 `add_child`。

## HBox 与 VBox：排列即控件

盒子不画任何东西、只当父——「排列」本身就是这个控件的全部。`layout()` 一趟走法：按收养次序遍历子控件，主轴上保留子自己的厚度、副轴上拉到盒子的厚度，游标跨过一个子加一次间距。行盒（HBox）横着走，列盒（VBox）竖着走，同一趟走法换了轴。隐藏的子件仍占位：显隐是画与输入的事，排列是结构的事。

三件事是调用方的责任，不做自动：加了子要重排，子的厚度变了要重排，盒子自己被 `set_bounds` 了要重排。嵌套盒子手工组合，次序外先内后——外层一趟先定下内层盒子的框，内层再排自己的子。判例把四种情形都立了字据（初始排、改间距重排、无变化的重排不申报、嵌套组合），「布局挪动就是 set_bounds 挪动」由申报判例直接守着。

## Slider：拖拽地基的第一个住户

滑块的交互三步全站在第十四章的地基上：按下即抓取（值跳到按下的位置），移动即拖拽（捕获保证越界的移动也到它手上，两端钳制在轨内），松手放手。为此 `on_pointer_down` 也带上了位置——B14 留下的小不对称（按下不带位、抬起移动带位）在「按下就要知道抓哪」面前站不住，三个指针回调统一带位，理由也统一：捕获世界里控件要自己知道指针在哪。

值的语义取最朴素的：值就是滑块左缘的偏移，0 到 `max()`，`max()` 是轨宽减手柄宽（手柄两像素宽，两端各留一像素的轨可见，手柄永不离轨）。`set_value` 钳制后比较，值没变就不申报不回调——跟 `set_visible` 的无操作径同一个口径。值回调是裸函数加上下文词，Button 的形状。键盘腿有意不做：左右箭头是宿主码，核心只点名 Tab、Enter、Space，滑块不猜；等哪一批把方向键收进核心词表，键盘腿落在这套值词汇上。

画法照单色屏的老实路数：轨是横贯中线的一行亮线，手柄是骑在上面的暗块——轨说范围，手柄说现值。

## 判例实录

期望写错一回，又是半开区间：申报判例起初以为旧框与新框（[0,4) 与 [4,8)）会级联合并成一条 [0,8)，忘了恰好共享一条边的矩形交为空、不触发级联——第二章的试金石在自家布局上应验，判例改成数两条、各守各框。

实现侧被编译器拦了两回，都值一碗茶：局部变量 `child` 把刚长出来的成员函数 `child(i)` 遮了（`child 不能用作函数`），换名了事；盒子第一版写了不存在的 `children_start()`（Widget 从来没有暴露过子数组），这才补上正经的 `child(index)` 取用口——先有判例要读子、再有接口开门的顺序，本来就是这仓库的走法。

红绿探针两根。第一根抹掉 HBox 的间距（游标不加分隔），红 2 处，改间距重排的两条边界断言当场对不上。第二根去掉滑块拖拽的护栏（悬停的移动也改值），红 6 处：悬停判例的值与计数、抓取后的计数时序、松手后悬停不改值，全链翻红。两根复原再绿。

## 验收

六道一条命令：

```console
$ VISOR_CHECK_JOBS=4 scripts/checks/acceptance.sh
acceptance: all green
```

亲手排一行。造一个 HBox，塞三个不同宽的 Rectangle，`layout()` 后逐个读 `bounds()` 看行排与副轴拉伸；`set_spacing(2)` 再 `layout()`，看游标分开。再放一个 Slider 进树，队列里按下、拖动、松手各来一遍（每事件一轮 `run_once`），读 `value()` 跟着走。

红绿实验两个。第一个，把 `box.cpp` 里 `cursor += width + spacing_;` 的间距抹掉，看 HBox 判例红（实录 2 处），复原再绿。第二个，把 `slider.cpp` 里 `on_pointer_move` 的 `if (dragging_)` 护栏去掉（补一句 `static_cast<void>(dragging_);`），看悬停判例红（实录 6 处），复原再绿。
