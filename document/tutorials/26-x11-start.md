# 第二十六章 X11 起步：选型与事件翻译

PC 窗口宿主线开工（2026-10-14 作者拍板 X11 起步，理由与测试策略收在待办的 PC 窗口站台文件），第一批照 B8/B17 的打法第三次复用：真窗口的部分等下一批，PC 判例能验的纯逻辑先在主树里长齐。本批两件半：选型与测试策略落档，`bindings/x11` 的事件翻译，外加一处被第一条真文本宿主点破的老口子。

## 选型：为什么是 X11

Xlib 是系统库，直连不算第三方依赖，这是零依赖约定在本线的具体化。无头判例的路先在机器上验过一遍：Xvfb 起一块固定尺寸的虚拟屏，读回走测试代码里的 XGetImage，断言沿用既有的像素差分口径，离屏差分判例保持回归底线不动。真窗口也有现成落点，WSLg（WSL 内置的图形支持）把 X 应用直接弹在 Windows 桌面上。Wayland 的无头要走 headless 合成器，起步就多养一个组件，等桌面语义那站再议。

## 空格的两张面孔

第二十二章立词表时埋的张力，被第一条真文本宿主点破了：产文本的宿主按码点送键，空格就是 32；而 kKeySpace 的 57 是 evdev 编号，激活消费者只认它——真键盘的空格键到不了按钮。Cinux 线其实早就在送 32（内核填了 ascii 就优先走 ascii），只是没有谁按下空格去点按钮，口子一直没显形。补口是一个新常量：`kCharSpace = 0x20`，Button、Checkbox、Dropdown 三处激活判断都认两份数字。两套编码在线上无法区分是词表接受的代价，消费者各读各的义。

## bindings/x11：事件翻译

与 cinux 线的分工同构：keysym 解析要查显示连接的键表，归 X 调用半边（那半边下一批才来，XLookupString 是它的活）；翻译本身是纯函数，不碰任何 X 连接。三张口：`translate_key` 吃 keysym 加按压布尔，`translate_button` 吃 XButtonEvent，`translate_motion` 吃 XMotionEvent。

键盘一张表：Backspace、Tab、Return 落核心点名的 evdev 值，方向键落带外值（keysym 的 0xff52 带不是核心比对的数，表就是两套编码的桥），可打印 ASCII 的 keysym 就是码点直通（空格的 32 从这条来），其余——功能键、小键盘变体、死键——译为空，与空表项同一条诚实拒绝线。指针：键 1 到 3 连号带位置透传，滚轮（4 起）是滚动不是按压，拒到滚动层存在的哪天；移动透传窗口坐标，负数照送，指针可以在窗左上方，核心裁剪它跟裁任何界外词一样。

## 判例与探针实录

判例七组：可打印带、空格双读、具名三键、方向键四向（按下抬起同码）、无名词拒绝、按钮与滚轮、负坐标移动。判例初版栽过一跤：optional 空值上直接解引用，探针突变下判例崩在中途（SIGABRT），照 cinux 的家法补上 has_value 守卫才有干净的计数。两根探针：箭头四行换成无人按键的键号，红八处（四方向乘按下抬起）；滚轮拒绝线放宽到键 5，红二处。

## 工具的漂移

一夜之间 clang-tidy 滚到新的大版本，新口径把老代码照出 77 处（尾逗号 55、有符号位运算 19、const 两处、lambda 一处），本批新文件自己也吃了好几课（字面量后缀要大写、宏要用直接提供它的头、std::array 的聚合初始化与指名初始化犯冲）。处置拍板全修码：尾逗号交给 tidy 自己带修，位运算分两类——字面量补 U 后缀、混算走 unsigned 是真类型修；位库的整数提升（子字宽的无符号数做位运算，被提升规则送回 int）是固有形态，NOLINT 段落配说明句收留。theme 的 corner_radius 顺带拿到默认值，两套预设定势省掉冗余字段。工具版本不设卡、漂移照单全收是仓库既定方针，这一批是方针第一次兑现在自己身上。

## 验收

六道一条命令：

```console
$ VISOR_CHECK_JOBS=4 scripts/checks/acceptance.sh
acceptance: all green
```

亲手翻一次词表。挑几个 keysym（XK_a、XK_Return、XK_Left、XK_F1），调 `translate_key` 看返回的是 KeyDown 带哪个码还是空。再手写一个 XButtonEvent（type 填 ButtonPress，button 分别填 1 和 4），看透传与拒绝的分界。

红绿实验两个。第一个，把 event_wire.cpp 箭头四行的 case 值改成没有键会用的数（比如 0x2001 起），看方向键判例红（实录八处），复原再绿。第二个，把 translate_button 的键号上限从 Button3 放宽到 Button5，看滚轮的两条拒绝判例红（实录二处），复原再绿。
