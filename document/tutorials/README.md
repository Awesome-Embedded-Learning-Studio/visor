# visor 跟跑教程

这批教程跟着 visor 前两个批次（B1、B2）的真实工序走，从空仓库搭出一个跨宿主 GUI 框架的头两层：构建骨架、几何词汇、位操作库、单色画布、笔、宿主表与离屏宿主，一道像素差分关卡，然后宿主表长出事件与时钟两项，固定容量队列与时钟回绕进场。正文把实现与测试写成成对推进的过程。被工具逮住的那些错误，比如链接器报出缺失实现的一次经历、tidy 教的指名初始化、PBM 头 8 字节算成 7 的乌龙、十六槽队列装不下十六个事件的想当然，都写成你会亲历的过程。每章收尾有一个可以自己执行并观察结果的验收。

## 读者需要什么底子

会 C++ 基本语法，见过模板，就够了。Concepts、CTAD 这些机制用到时当场解释，不要求先修。要会用命令行，CMake 与 CTest 的命令都是逐条给出的普通写法。不需要 GUI 或嵌入式经验，第一章连一行图形代码都还没有。

手边要有一台 Linux（或 WSL）机器。工具链版本对照名册：GCC 16.2.1、CMake 4.4.3、Ninja 1.13.2、clang-format 与 clang-tidy 22.1.8、Doxygen 1.18.0，configure 阶段会硬卡其中三个，版本不符直接停。

## 读完能得到什么

一个你自己一步步搭出来的仓库：可构建、可测试、可差分验证的 1bpp 绘制链路，从 `Point` 一直通到 PBM 图片文件。

一套可迁移的做法：

- 测试先行。
- 字面断言，把 `0xF8` 这类字节值写死在测试里。
- 工具版本锁。
- 双层边界处理：画布拒写，笔先裁剪。
- 用独立参考图做像素差分。
- 时长只用无符号减法：时钟值可能回绕，比较绝对值在回绕边界上就是错的。

对每个接口决定的理解：为什么叫 `Color` 不叫 `MonoState`、为什么宿主表方向是核心画宿主收、为什么 `plot` 越界静默、为什么笔的模板挂在画布类型上。

## 各章导览

- [第一章 起步与骨架][ch1]：先把验证立起来。CMake 骨架、CTest 统一入口、格式与静态检查、文档基建，一条命令链跑完，全部检查通过。
- [第二章 几何词汇表][ch2]：`Point`/`Size`/`Rect` 模板家族与半开区间语义。恰好共享一条边的两个矩形交为空，这条试金石用例（专门检验语义有没有走样的判例）检验全部边界判断。
- [第三章 位操作库][ch3]：`BitRange`/`BitMask`/`Bitmap` 自 Cinux（作者的 x86-64 教学操作系统）移植，顺手修掉两个真问题：`unsigned long` 在 32 位平台说谎，`operator|` 在 8 位字上收窄。
- [第四章 画布][ch4]：1bpp（每像素一比特）位布局（行主序、MSB 在前、填充位恒零），奇数宽度末字节 `0xF8` 的字面断言，`Color` 这个名字的定名理由。
- [第五章 笔][ch5]：`plot` 与 `fill` 两级原语，越界静默的设计理由，const 笔语义（笔不变纸变），模板挂在画布类型上给 RGB565（16 位彩色格式，计划中）留缝。
- [第六章 宿主表与离屏宿主][ch6]：核心与外界的边界只此一张表，方向是核心画宿主收（核心产出像素，宿主只接收上屏），离屏宿主只收整幅，PBM（一种最简的位图文件格式）导出与 `fstream` 不认裸 `string_view` 的实况。
- [第七章 差分关卡][ch7]：五矩形场景三轮比对，普通构建与 ASan/UBSan（内存错误与未定义行为检测器）构建各跑一遍，项目第一张留存下来的图片与它的正确读法（位 1 渲染为黑）。
- [第八章 事件与时钟][ch8]：宿主表长出事件与时钟两项。`RingQueue`（自 Cinux 移植的第二件）一格留空、满则拒新，五个事件词以 `std::variant` 承载，时钟回绕靠无符号减法，离屏宿主喂合成事件与脚本化时间，TSan 第六道进验收。

## 怎么读

按顺序读，每章的验收亲手跑一遍，把验收里的红绿实验也做一遍：把断言改错看测试转红，再复原。章节之间是依赖关系：第四章用第三章的位词汇，第六章用第四章的位布局公式，第七章把前六章全部串起来。跳着读会缺上下文。

## 口径

教程成文于 2026-10-07，第一至七章对应 B1 完成时的仓库现状，2026-10-11 随收尾评审的四处小改同步过一次（概念改名 `Arithmetic`、`RectF`/`RectD` 别名改正、概念头注释与静态断言）；第八章随 B2（2026-10-11）加入，对应 B2 完成时的仓库现状。全部代码示例摘自仓库原文，工具链版本与命令以名册为准。

代码注释里的 Ch1、ch2 这类章号按项目的规格章节表计数（B1 对应第一章，B2 对应第二章），与本书的章号不是一套，读到时按批次对应即可。

核心侧的运行循环（事件泵）、脏区、控件树、RGB565、真实 OLED 开发板、取模（把汉字与图片转成点阵数据）转换逻辑这些目前都没有实现，文中只作为计划中的下一站出现。事件词汇、固定容量队列与毫秒时钟自第八章起已实现。

git 首提交于 2026-10-11 完成，教程不以提交为验收步骤。
